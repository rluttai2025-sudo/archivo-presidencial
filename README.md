# Archivo presidencial comparado

Sitio estático en español para explorar los presidentes de Estados Unidos y Chile por periodo, partido, reelección, origen, conflictos, fallecimiento en el cargo y ascendencia.

## Publicación

El sitio no requiere proceso de compilación. El contenido listo para publicar está en `dist/`.

Para verlo localmente, abre `dist/index.html`. En GitHub Pages, Cloudflare Pages o cualquier alojamiento estático, configura `dist` como directorio público.

## Contenido

- 45 presidentes de Estados Unidos.
- 38 mandatarios de Chile.
- Selector de país y filtros combinables.
- Retratos incluidos localmente en formato WebP.
- Fichas con periodos, principales acciones y conflictos.
